# Configuration overview

Lumen reads configuration from environment variables first, then `lumen.yaml`,
then built-in defaults. Environment variables always win.

## Core settings

| Setting | Environment variable | Default |
| --- | --- | --- |
| Database URL | `LUMEN_DATABASE_URL` | — (required) |
| Listen port | `LUMEN_PORT` | `8080` |
| Log level | `LUMEN_LOG_LEVEL` | `info` |
| Retention window | `LUMEN_RETENTION_DAYS` | `365` |

## Example

```yaml title="lumen.yaml" {2,5-6}
server:
  port: 8080
  logLevel: info

retention:
  days: 365
```

<Callout type="danger">
Lowering `retention.days` deletes history beyond the new window on the next
maintenance run. The deletion is permanent.
</Callout>
